Equations used to Cook The Perfect Egg



Hello!

We like eggs, especially boiled eggs. We like eggs so much we created this app to make the perfect boiled eggs.

Cookin Instructions

Before starting the timer, bring the water to a boil. Then add the eggs and start the timer by clicking Start.

Simple Options

You can choose what type of egg you want (soft to hard boiled), the size of the egg, and whether or not its directly from the fridge. The app will take in your options to calculate the time it takes to make perfectly boiled eggs.

Advanced Options

If you are looking to make the most perfect perfect eggs then click on the Show Advanced Options. These options are for the hardcore boilers out there who want the perfect perfect eggs. You can specify what the eggs final temperature is going to be, the diameter of the egg, the egg's current temperature, the water's current temperature, the current altidude, and the air pressure. These parameters will be used to calculate the time it takes to make the perfect perfect eggs. You can view the egguations used below.

Location

The location tracking is COMPLETELY OPTIONAL and even if you do use it, we do not store your location information. This information will be used to improve the accuracy of the time as it will give the altidude of where your at. You can also manually set this in the Advanced Options.

Yeelight Feature

If you are in possession of a Yeelight Device, the app will automatically connect to it. When the timer goes off it will make the light flash to indicate your eggs are ready. The settings page will displace current devices connected.

Egguations used

Time to cook egg[1]


$$t_E = {R^2 \over (π^2 α)} \bigg(ln⁡{(T_b-T_0) \over (T_b-T_c )} \bigg)^2$$
$$t_E = time \text{ } to \text{ } cook \text{ } egg \text{ } in \text{ } seconds$$ $$T_b = temperature \text{ } of \text{ } boiling \text{ } water$$ $$T_c = desire \text{ } Temperature \text{ } at \text{ } the \text{ } center \text{ } of \text{ } the \text{ } egg$$ $$T_0 = initial \text{ } temperature \text{ } of \text{ } the \text{ } egg$$ $$R = 0.0225→0.0223 \text{ } m \text{ } (radius \text{ } of \text{ } spherical \text{ } approximation \text{ } of \text{ } egg)$$ $$α = 1.53*10^{-7} m^2 s^{-1}$$

Determing temperature of boiling water[2]


$$T_2 = \bigg [{1 \over T_1} -({R ln⁡{P_2 \over P_1 } \over ∆H_{vap} })\bigg]^{-1}$$
$$T_2 = temperature \text{ } in \text{ } Kelvin$$ $$∆H_{vap} = 40660 \text{ } Joules*mol^{-1}$$ $$R = 8.314 \text{ } Joules*K^{-1}*mol^{-1}$$ $$P_1 = 101325 Pascals$$ $$T_1 = 373.15°K$$
In order to get $T_2$ from this equation we first need to find $P_2$ (pressure 2).
There are two ways to get $P_2$
Equation 2 is more accurate that equation 1.

Equation 1[3]


$$P_2 = 101325(1-2.25577*10^{-5}*h)^{5.25588}$$
$$h=altitude \text{ } above \text{ } sea \text{ } level \text{ } (meters)$$ $$P_2 \text{ } is \text{ } in \text{ } Pascals$$

Equation 2[4]


$$P_2 = P_0*e^{{-Mgh \over RT_{air} }}$$
$$P_0 = 101325 \text{ } Pascals$$ $$M=0.0289644 \text{ } Kg*mol^{-1}$$ $$R=8.31432 \text{ } Joules*mol^{-1}*K^{-1}$$ $$h=altitidue \text{ } above \text{ } sea \text{ } level \text{ } (meters)$$ $$g=9.80665 \text{ } m*s^{-2}$$ $$T_{air}=air \text{ } temperature \text{ } at \text{ } altitude \text{ } h$$
