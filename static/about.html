Equations used to Cook The Perfect Egg



Equations used

Time to cook egg[1]


$$t_E = {R^2 \over (π^2 α)} \bigg(ln⁡{(T_b-T_0) \over (T_b-T_c )} \bigg)^2$$
$$t_E = time \text{ } to \text{ } cook \text{ } egg \text{ } in \text{ } seconds$$ $$T_b = temperature \text{ } of \text{ } boiling \text{ } water$$ $$T_c = desire \text{ } Temperature \text{ } at \text{ } the \text{ } center \text{ } of \text{ } the \text{ } egg$$ $$T_0 = initial \text{ } temperature \text{ } of \text{ } the \text{ } egg$$ $$R = 0.0225→0.0223 \text{ } m \text{ } (radius \text{ } of \text{ } spherical \text{ } approximation \text{ } of \text{ } egg)$$ $$α = 1.53*10^{-7} m^2 s^{-1}$$

Determing temperature of boiling water[2]


$$T_2 = \bigg [{1 \over T_1} -({R ln⁡{P_2 \over P_1 } \over ∆H_{vap} })\bigg]^{-1}$$
$$T_2 = temperature \text{ } in \text{ } Kelvin$$ $$∆H_{vap} = 40660 \text{ } Joules*mol^{-1}$$ $$R = 8.314 \text{ } Joules*K^{-1}*mol^{-1}$$ $$P_1 = 101325 Pascals$$ $$T_1 = 373.15°K$$
In order to get $T_2$ from this equation we first need to find $P_2$ (pressure 2).
There are two ways to get $P_2$
Equation 2 is more accurate that equation 1.

Equation 1[3]


$$P_2 = 101325(1-2.25577*10^{-5}*h)^{5.25588}$$ $$h=altitude \text{ } above \text{ } sea \text{ } level \text{ } (meters)$$ $$P_2 \text{ } is \text{ } in \text{ } Pascals$$

Equation 2[4]


$$P_2 = P_0*e^{{-Mgh \over RT_{air} }}$$ $$M=0.0289644 Kg*mol^{-1}$$ $$R=8.31432 Joules*mol^{-1}*K^{-1}$$ $$h=altitidue \text{ } above \text{ } sea \text{ } level \text{ } (meters)$$ $$g=9.80665 m*s^{-2}$$ $$T_{air}=air \text{ } temperature \text{ } at \text{ } altitude \text{ } h$$
